【上线（GitHub Pages，纯网页操作）】
  1. github.com → New repository → 名 viitrix-site → Public → Create
  2. Add file → Upload files → 把本目录全部内容（含子文件夹）拖进去 → Commit changes
     单次上传上限 100 个文件；本包 100+ 个，建议分两批：先 images/，再其余
  3. Settings → Pages → Source: Deploy from a branch → main / (root) → Save
  4. 等 1~2 分钟 → https://<用户名>.github.io/viitrix-site/
